# X投稿ネタ｜最新ニュース収集ダッシュボード

RSSまたはAtomフィードから最新記事を最大5件取得し、タイトル・URL・公開日時・概要をカード形式で表示するStreamlitアプリです。Geminiが各ニュースから3パターン、最大15本のX投稿案を自動生成します。

## Windows 10で起動する方法

1. ZIPファイルを右クリックし、「すべて展開」を選びます。
2. 展開したフォルダ内の `run_app.bat` をダブルクリックします。
3. 初回のみ必要なライブラリが自動でインストールされます。
4. ブラウザが自動的に開き、アプリが表示されます。

Pythonが未インストールの場合は、先にPython 3.10以降をインストールしてください。インストール画面では「Add Python to PATH」にチェックを入れます。

## ターミナルから起動する方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 使い方

1. [Google AI Studio](https://aistudio.google.com/app/apikey)でGemini APIキーを取得します。
2. 画面左側の「Gemini APIキー」にキーを入力します。
3. 必要なら「あなたの経験・意見メモ」を入力します。
4. 「RSSフィードのURL」にRSSまたはAtomのURLを入力します。
5. 「最新ニュースを取得」を押します。
6. 最新記事と、記事ごとの3パターンのX投稿案が表示されます。
7. 投稿案の右上に表示されるコピーアイコンから文章をコピーできます。

APIキーが未入力でもニュース取得機能は利用できます。その場合、後からキーを入力して「表示中のニュースからX投稿案を生成」を押せます。

## 生成する3パターン

- A：専門家による解説
- B：初心者への警鐘・アドバイス
- C：個人の共感・オピニオン

各投稿はハッシュタグ2個を含めて140文字以内に自動調整します。経験メモが空欄の場合、AIは架空の個人体験を作らず、意見表現だけを使用します。

## Streamlit Community CloudでAPIキーを設定する方法

アプリの「Settings」→「Secrets」に、次の形式で登録します。

```toml
GEMINI_API_KEY = "取得したAPIキー"
```

APIキーをコードやGitHubへ直接書き込まないでください。

## 主な仕様

- Streamlit + feedparser + Google GenAI SDK
- RSS / Atom対応
- 最新5件をカード表示
- 取得結果を5分間キャッシュ
- 通信エラー、URL不正、記事なしの場合の案内表示
- RSS概要内のHTMLタグを除去し、安全なテキストとして表示
- ニュース5件分の投稿案を1回のLLMリクエストで一括生成
- 3つの切り口、140文字以内、ハッシュタグ2個に自動整形
